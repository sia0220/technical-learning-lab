# Technical Learning Lab
This repository documents my continuing development in software engineering, product security, cloud security, and technical problem solving.

I am a Computer Science student at the University of Michigan-Dearborn with an expected graduation date of May 2027. The purpose of this repository is to make my learning reproducible, tested, and evidence based as I prepare for early career opportunities in the San Francisco Bay Area.

## Current Focus

- Strengthening Python programming and independent debugging
- Practicing data structures and algorithms
- Writing and running automated tests with pytest
- Developing secure software engineering habits
- Building practical Google Cloud and IAM experience
- Learning to use AI development tools responsibly
- Recording what I can reproduce and explain independently

## Repository Organization

- 'weeks/' - Dated learning periods containing code, tests, and progress logs
- 'templates/' - Reusable templates for DSA problems, weekly reviews, and AI assisted sessions
- 'repeats/' - Spaced repetition attempts for previously solved problems 
- 'security-notes/' - Security concepts, threat modeling exercises, and secure design notes
- 'gcp-labs/' - Google Cloud labs covering IAM, service identities, secrets, logging, cost controls, and teardown
- 'ai-assisted-development/' - Documented Clause Code and Gemini Code Assist sessions
- 'project-designs/' - Architecture notes and designs for larger portfolio projects

Folders are added when the first completed artifact is available.

## Evidence Standard

An activity is considered complete only when I can provide one or more of the following:

- Working code
- Automated tests
- A reproducible lab
- A design or threat model
- A written explanation in my own words
- A reviewed AI assisted development log
- A repeat attempt demostrating retained understanding
